🧪 How to Run & Test
​Option 1: Run Locally / On Mobile Browser
​Download or clone this repository.
​Open omnishop_firetv.html in any web browser (Chrome, Safari, Firefox).
​Test touch interactions or use your keyboard arrow keys (ArrowUp, ArrowDown, ArrowLeft, ArrowRight, Enter) to simulate a Fire TV remote.
​Option 2: Fire TV / Android TV Deployment
​Host omnishop_firetv.html on GitHub Pages or any static web host.
​Open the URL in the Silk Browser or Downloader app on your Fire TV Stick.
​Use the Fire TV remote D-Pad to navigate and interact with the store channels and products.
​🔗 Live API Integration
​The frontend connects securely to the live B2B extraction engine:
​Base API: https://agamm-aga.onrender.com
​Extraction Route: https://agamm-aga.onrender.com/api/v1/extract?url={TARGET_URL}&api_key=demo-test-free
